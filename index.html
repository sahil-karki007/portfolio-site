    Bengaluru House Price Predictor

    Bengaluru House Price Predictor is a machine learning web application that predicts property prices using Python, scikit-learn, FastAPI, and React. It processes 13,320 property listings, cleans the data into 10,223 records with 229 features, and uses Linear Regression to achieve an R² score of 0.80. The model is optimized for lightweight deployment and integrated with a FastAPI backend and React frontend to deliver real-time house price predictions.
